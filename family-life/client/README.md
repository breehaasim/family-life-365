# Family Life website (React + Vite)
Run: `npm install` then `npm run dev` | Deploy: `npm run build` (Vercel/Netlify).
Saara content `src/data.js` mein hai (phone, WhatsApp, email, stages, services, FAQ, images, testimonials on/off). `TODO` comments client ke pending points hain.
Images: apni photos `public/images/` mein rakhein aur `IMG` mein '/images/name.jpg' likhein.
Chatbot (`src/Chatbot.jsx`): rule-based, booking WhatsApp par jati hai. Asli AI ke liye ise serverless API se jodein.
